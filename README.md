# Substitution-cipher
Program written is C++ cryptography program which reads text message from input file and then encodes or decodes message through substitution cipher. Main aim of program is to change alphabetic characters in coded letters and also change those back in normal text. Rule of project is followed by program that cipher must be according to total number of characters in message. In this character count, letters, spaces, punctuation marks, and other symbols are included. By this length, two values known as offset and spacing are calculated by program. By these two values, cipher lookup table is made. Structure of program is divided in separate functions such that each part of task is easy for managing. By toLowerCase function, all uppercase letters are  changed to lowercase letters in message. As cipher is applied only to lowercase alphabetic characters, so this is required. By function of buildCodeTable, lookup table array of size 26 is created. Each position of this array shows one alphabet letter from a to z, and formula is used for calculating coded position of each letter. By function of displayCodeTable, contents of this table are shown on screen so cipher values are verified by user. By function of encodeMessage, process of encoding is performed. Every character in message is checked. If character is lowercase letter, then it is changed in its coded equivalent through lookup table. All non-letter characters like spaces, commas, and quotation marks not changed. By function of decodeMessage, reverse process is performed. For each coded lowercase letter, lookup table is searched for finding matching value, then that value is converted back to original alphabet letter. In main function, input file name is entered by user. File is opened by program, message is read, and length of message, offset, and spacing is calculated. After that, code table is built and shown. User is then asked for choosing whether to encode or decode message. After processing, output file name is entered by user, and final message is written to that file.
